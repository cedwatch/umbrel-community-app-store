# NetWatch — Umbrel App

ISP stability monitor — tracks your internet connection 24/7 and visualizes uptime, speed, and dropout history.

## Features

- Live download / upload / ping charts
- 24-card recent tests horizontal scroll
- 14-day dropout heatmap
- 6 KPI cards — avg speed, best, worst, uptime %
- 3 skins — Kampot dark green, Mékong amber, Kep light
- Powered by [MySpeed](https://myspeed.dev) (install separately on Umbrel)

## Requirement

NetWatch proxies MySpeed's API. Install **MySpeed** on your Umbrel first.

## Install

Add the [cedwatch store](https://github.com/cedwatch/umbrel-community-app-store) to Umbrel, then install NetWatch from the Networking category.

## Source

- Docker image: `ghcr.io/cedwatch/netwatch:latest`
- Store: [cedwatch/umbrel-community-app-store](https://github.com/cedwatch/umbrel-community-app-store)
