BlockBoard — Umbrel App

Real-time Bitcoin dashboard. No tracking. No ads. No account. Just pure signal.

**Live demo:** [blockboard.live](https://blockboard.live)

## Features

- Live BTC price — 8 currency pairs (USD, EUR, GBP, JPY, CHF, CAD, AUD, PAXG)
- Mempool fees (Fast / Hour / Eco) with live fee meter
- Block height, hashrate & difficulty, last block timer
- Candle chart — 9 ranges (1h → all-time) with crosshair
- ETF 24h flow, Lightning & Liquid Network stats
- Halving countdown
- BlockBoard Pulse — proprietary sentiment index
- Weather + timezone clock
- 8 skins — PWA installable

## Install

Add the [cedwatch store](https://github.com/cedwatch/umbrel-community-app-store) to Umbrel, then install BlockBoard from the Finance category.
